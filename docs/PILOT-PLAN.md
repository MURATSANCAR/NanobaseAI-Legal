# Pilot Plan

1. Veri hazırlığı: sınıflandırma, privacy, expert assignment, golden dataset.
2. Baseline: parser/requirement/compliance/risk/performance.
3. Konfigürasyon: ontology, terminology, policy, prompt, workflow, report template.
4. Kontrollü pilot: gerçek proje, human approval, shadow, error analysis, feedback.
5. Kabul: UAT, security, performance, backup/restore, offline install, sign-off.

Minimum ingestion: 20–50 şartname; idari/sözleşme/zeyilname; katalog/sertifika/teklif; geçmiş
sonuçlar; compliance matrix; risk/soru/rapor örneği; kurum terimleri; approval akışı; user/role.

Admin portalında operasyon, AI kalite ve pilot checklist görünür. Skor yalnız kanıtlı
Security/Backup/Restore/Evaluation/UAT/Offline maddelerinin oranıdır; eksik madde açıkça bekler.
