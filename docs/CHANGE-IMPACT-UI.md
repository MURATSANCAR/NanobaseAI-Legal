# Change Impact UI

Kullanıcı dokümanı ve iki gerçek sürümü seçer. Change set ekranı eklenen,
silinen, değişen ve unchanged clause’ları; similarity, confidence ve review
durumuyla listeler.

Uzman clause ID eşleşmesini düzenleyip onaylayabilir. Etki analizi butonu yalnız
bu change set için graph traversal çalıştırır. Sonuç paneli etkilenen entity
türü, impact concept ve confidence gösterir.

Backend stale kayıtlarını oluşturur; eski analiz kaydı UI’dan silinmez. Full
project re-analysis otomatik tetiklenmez.
