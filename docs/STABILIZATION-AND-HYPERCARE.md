# Stabilization ve Hypercare

Stabilization yalnız `DEPLOYED` release için, geçerli başlangıç/bitiş aralığı ve aktif
monitoring/support policy sürümleriyle açılır.

Yakın izleme: error rate, queue depth, model latency, parser failure, manual review,
feedback, security alert, backup ve storage.

Hypercare policy günlük sistem kontrolü, triage, kullanıcı görüşmesi, kalite/kapasite,
model, backup ve security alert incelemesini tanımlar. Görevlerin yürütülmesi dinamik
workflow motoruna aittir.

Production deployment olmadığı için stabilization window oluşturulmamıştır.
